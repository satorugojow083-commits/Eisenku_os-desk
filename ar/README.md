# EISENKU AR

Escritorio flotante que se controla con las manos (cámara frontal), la voz o el tacto.
Funciona en tableta, celular y PC. Se instala como app y, después de abrirse una vez con internet, funciona sin conexión.

## Gestos
- **Pellizco** (pulgar + índice): tomar, mover y tocar botones.
- **Pellizco con las dos manos** sobre una ventana: escalar y girar.
- **Palma abierta 1 segundo**: menú circular de apps.
- Pellizco sobre el contenido de una ventana y mover: desplazar.

## Apps incluidas
Notas · Tareas · Galería flotante · Asistente de voz · Reloj y temporizador · Kit de stream · Exposiciones · Juego "Atrapa estrellas" · Atajos

## Publicarla gratis (GitHub Pages)
1. Crea un repositorio público en GitHub, por ejemplo `eisenku-ar`.
2. Sube todos los archivos de esta carpeta (Add file > Upload files).
3. Settings > Pages > Branch: `main` / `(root)` > Save.
4. Abre `https://TU-USUARIO.github.io/eisenku-ar/` en Chrome de tu tableta.
5. Menú de Chrome > **Instalar app** o **Agregar a pantalla principal**.

La cámara necesita HTTPS: no funciona abriendo el archivo directo desde la carpeta.
